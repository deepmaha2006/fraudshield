How to connect a phone
  1. Install the FraudShield Android companion (source in android-companion/ — open it in Android Studio and press Run).
  2. Pair a device here and enter the server URL and device token in the app. The phone must reach this server: same Wi-Fi, or set PUBLIC_BASE_URL to a tunnel / public host.
  3. Grant the SMS permission. Each incoming SMS is sent to POST /api/ingest/sms, analysed live, and a notification warns on scams.
  4. Alternatively, any SMS-forwarder app that can POST JSON with header Authorization: Device <token> and fields sender, body works too.
