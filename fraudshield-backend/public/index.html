Detection pipeline

Measured, not looked up

A brand-new phishing domain is on no list. These are the properties FraudShield computes for every link instead.

URL structure

Homograph and punycode tricks, embedded brand domains, IP hosts in decimal or hex, "@" credential tricks, entropy of algorithmically generated names, executable payloads.

DNS

Resolution, NXDOMAIN, fast-flux TTL patterns, MX / SPF / DMARC presence, and refusal of links that point into private networks.

Redirect chain

Follows every hop the way a browser would — cross-domain bounces, HTTPS downgrades, shortener-hidden destinations — then judges the final landing page.

TLS certificate

Chain validity, host mismatch, self-signed or expired certificates, certificates minted hours ago, and organisation validation.

Domain registration

Live RDAP query to the authoritative registry: registration age, registry holds, unregistered domains, throwaway registration terms.

Page behaviour

Password and card / OTP / Aadhaar fields, forms that post to another domain, brand claimed vs. domain owned, cloned assets, obfuscated scripts, APK lures.

Coverage

Where attacks actually arrive

Gmail, push-based

An IMAP IDLE connection receives each message the instant it lands. SPF, DKIM and DMARC results, display-name spoofing and deceptive link text are analysed alongside every link. Malicious mail gets a Gmail label.

Android SMS

The companion app forwards each incoming SMS to your server and raises a phone notification when it is a scam — KYC, parcel, electricity-bill and remote-access lures included.

SOC console

Live detection feed, triage queue with full evidence trail, defanged IOCs, JSON / CSV export and period reports — built for analysts, not marketing.
